AO 设备/通道/音量

AO 输出音量调用 ss_mpi_ao_set_volume，单位是 dB，不是百分比；厂商示例测试范围为 -15~6 dB，0 dB 为默认基准，6 dB 为示例测试最大增益。

音频编码

每帧采样点可选 80/160/240/320/480/1024/2048；ADPCM IMA 类型需要 161/241/321/481。G726：0/1/2/3 为 16/24/32/40 kbps RTP，4/5/6/7 为 16/24/32/40 kbps MEDIA。

音频解码

音频算法参数

掩码 0 表示关闭算法；16 kHz 下 320 点等于 20 ms。AI Record 支持 16 kHz/48 kHz，AI Talk 支持 8 kHz/16 kHz，AO VQE 支持 8 kHz/16 kHz/48 kHz。

采集/播放算法

模拟音频编解码器控制

ACODEC 参数范围：I2S1 采样率 1~11 对应 8000/11025/12000/16000/22050/24000/32000/44100/48000/64000/96000 Hz；麦克风输入源 0/1/2 对应 IN0/IN1/差分输入；总输入/总输出音量按 dB 写入，厂商音频实现依据为 -78~80 dB；Boost 为 0/1；MIC 模拟增益为 0~31；ADC/DAC 音量寄存器为 0x00~0x7e，0x7f 表示静音；静音、上下电、软静音类参数为 0/1。

麦克风测试

录音固定输出 16 kHz / 16 bit WAV。Boost：0 关闭、1 开启；MIC 模拟增益：0~31；总输入音量：-78~80 dB，数值越大录音越响，厂商建议常用 20~50 dB。

扬声器测试

播放频率的音量百分比只缩放生成的正弦 PCM；播放语音文件的响度由文件自身幅度、AO 输出音量和 ACODEC 输出/DAC 配置共同决定。播放链路固定按 16 kHz / 16 bit PCM 输出。
